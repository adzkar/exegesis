# exegesis

Convert PDFs — especially multi-column academic papers — into clean,
reflowable EPUB ebooks. Rule-based layout analysis over PyMuPDF blocks;
no OCR, no ML dependencies.

- [Conversion report](report/index.html) — per-paper layout and stats
  from the local corpus
- [Pipeline diagram](pipeline.md) — how a page flows through the stages
